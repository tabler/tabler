Added the `Kbd` component with a docs page and a demo page, and the `.kbd-sm` and `.kbd-lg` sizes. `.kbd` now has its own padding, color and background, and the default font size is smaller (`$font-size-sm` instead of the h5 size). An icon inside a key scales with the key.
