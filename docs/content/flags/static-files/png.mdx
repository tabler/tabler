## Usage

The package has one directory per visual style (`rounded`, `plain`, `gradient` and `shiny`) and, inside each, one directory per height in pixels. The sizes are 12, 16, 24, 32, 48, 64 and 128. The file name is the flag's slug:

```text
node_modules/@tabler/flags-png/dist/rounded/32/poland.png
```

Pick the size that matches how big the flag is on screen, or one step up for high-density displays:

```html
<img src="node_modules/@tabler/flags-png/dist/rounded/48/poland.png" alt="Poland" width="30" height="24" />
```

PNG files are the right choice for HTML emails, where SVG is not supported by most clients, and for chat and design tools that only take raster images. On a web page, prefer the [SVG files](/flags/static-files/svg) or the [CSS plugin](/flags/css).

The full list of flags and slugs is in the [repository README](https://github.com/tabler/tabler-flags#flags).
