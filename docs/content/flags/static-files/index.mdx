Every Tabler flag is available as a set of static files. Download [SVG](/flags/static-files/svg) for the web and design tools, or [PNG](/flags/static-files/png) for emails, chats and tools without vector support. Both packages ship each flag in four styles: `rounded`, `plain`, `gradient` and `shiny`.
