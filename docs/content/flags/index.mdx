Tabler Flags is a collection of { flags.length } flags: every country, the territories, unions such as the European Union, and a few other flags without an ISO code. Every flag is drawn on the same 5:4 canvas, so a row of flags lines up whatever the countries are.

<span class="flag flag-lg flag-country-pl"></span>
<span class="flag flag-lg flag-country-us"></span>
<span class="flag flag-lg flag-country-jp"></span>
<span class="flag flag-lg flag-country-br"></span>
<span class="flag flag-lg flag-country-eu"></span>
</Example>

You can use the flags in three ways:

- **[CSS plugin](/flags/css)**: add the `flag` and `flag-country-*` classes to a `<span>`. Works with plain HTML and any framework, and needs only one extra stylesheet. This is the plugin that ships with Tabler.
- **[Libraries](/flags/libraries)**: render flags as native, tree-shakable components in [React](/flags/libraries/react), [Vue](/flags/libraries/vue), [Preact](/flags/libraries/preact) or [Astro](/flags/libraries/astro), with type-checked props and a choice of four visual variants.
- **[Static files](/flags/static-files)**: download every flag as an [SVG](/flags/static-files/svg) or [PNG](/flags/static-files/png) file, for design tools, emails and anything that is not a web page.

All three use the same artwork, so you can mix them or switch between them without visual changes.

## Quick start

For the CSS plugin, include the stylesheet from a CDN and add a `<span>` with the country's class:

<CdnImportPlugin plugins={['flags']} />

<Example centered html={`<span class="flag flag-country-pl"></span>`} />

For a framework project, install the package for your stack and import the flags you need - only the flags you import end up in your bundle:

```jsx
import { FlagPoland } from '@tabler/flags-react';

<FlagPoland size={32} />
```

The [CSS plugin](/flags/css) page documents all classes, sizes and the full list of flags; each [library page](/flags/libraries) covers installation and props for its framework.
