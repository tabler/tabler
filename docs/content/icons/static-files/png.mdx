## Installation

<TabsPackage name="@tabler/icons-png" />

or just [download from Github](https://github.com/tabler/tabler-icons/releases).

All PNG files are stored in `icons` subdirectory.

## CDN

### Outline version

Load the outline version of an icon as an image straight from the `icons/outline` directory of the CDN package:

```html
<img src="https://unpkg.com/@tabler/icons-png@latest/icons/outline/home.png" />
```

### Filled version

Use the `icons/filled` path to load the filled version of an icon:

```html
<img src="https://unpkg.com/@tabler/icons-png@latest/icons/filled/home.png" />
```

`latest` always serves the newest icons. Pin a version number instead when you need the set to stay stable.
