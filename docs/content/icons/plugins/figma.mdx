The Tabler Icons Figma plugin puts the whole icon set inside Figma. You search for an icon, preview it and insert it into the design, without switching to the browser to download an SVG. It works the same for dashboards, websites and mobile app designs.

## Usage

Install the plugin from the Figma community and open it from the plugins menu in your file. Type a keyword to search, then click an icon to insert it. Once it's in the design, you can change its size, color and stroke width.
