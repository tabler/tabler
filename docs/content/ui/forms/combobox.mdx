## Overview

A combobox looks like a select, but its options are ordinary HTML, so an item can hold an icon, a description, a badge or an image. It is a toggle button paired with a `.dropdown-menu`. JavaScript handles the menu, the selection, a hidden input for form submission and the keyboard.

Add `data-bs-toggle="combobox"` to a `<button class="form-select combobox-toggle">`, followed by a `.dropdown-menu` with `.dropdown-item` buttons. Every selectable item needs a `data-bs-value`.

<Example column overflow="visible">
<div class="w-100">
  <button class="form-select combobox-toggle" type="button" data-bs-toggle="combobox" data-bs-placeholder="Select an item…" data-bs-name="option">
    <span class="combobox-value"></span>
  </button>
  <div class="dropdown-menu">
    <button class="dropdown-item" type="button" data-bs-value="1">Option one</button>
    <button class="dropdown-item" type="button" data-bs-value="2">Option two</button>
    <button class="dropdown-item" type="button" data-bs-value="3">Option three</button>
  </div>
</div>
</Example>

## Native select

Add `data-bs-toggle="combobox"` to a `<select class="form-select">` and the combobox builds the toggle and the menu from its options. The `<select>` stays in the DOM, keeps its value and fires a normal `change` event, so forms, validation and your own scripts work as before. This is the mode to use in place of [Tom Select](/ui/plugins/advanced-select).

<Example column overflow="visible">
<div class="w-100">
  <label class="form-label" for="combobox-fruit">Fruit</label>
  <select class="form-select" id="combobox-fruit" data-bs-toggle="combobox" data-placeholder="Pick a fruit">
    <optgroup label="Citrus">
      <option value="orange">Orange</option>
      <option value="lemon">Lemon</option>
    </optgroup>
    <optgroup label="Berries">
      <option value="strawberry">Strawberry</option>
      <option value="blueberry">Blueberry</option>
    </optgroup>
  </select>
</div>
</Example>

- `<optgroup>` becomes a `.dropdown-header`, and `disabled` options stay disabled.
- The placeholder comes from `data-placeholder`, or from the text of an empty `<option value="">`.
- A search field is added automatically. Turn it off with `data-bs-search="false"`.
- Classes such as `.is-invalid` and `.form-select-sm` are copied to the toggle.

### Multiple

Add `multiple` and the picks show as tags. Click a selected item in the menu to remove it. <kbd>Backspace</kbd> removes the last tag. There is no limit by default; add `data-bs-max-items` if you want one.

The tags stay on one line so the field keeps its height. The ones that do not fit are replaced by a `+N` tag, and clicking it opens the menu. Set `data-bs-tags-overflow="wrap"` to let the tags wrap onto more lines instead.

<Example column overflow="visible">
<div class="w-100">
  <select class="form-select" multiple data-bs-toggle="combobox" data-placeholder="Pick fruits">
    <option value="apple" selected>Apple</option>
    <option value="banana" selected>Banana</option>
    <option value="cherry" selected>Cherry</option>
    <option value="date" selected>Date</option>
    <option value="elderberry" selected>Elderberry</option>
    <option value="fig" selected>Fig</option>
    <option value="grape" selected>Grape</option>
    <option value="kiwi">Kiwi</option>
    <option value="mango">Mango</option>
  </select>
</div>
</Example>

### Rich options

### Menu container

By default the menu sits right after the toggle. Set `data-bs-container="body"` to append it to the page body, so a card or modal with `overflow: hidden` cannot clip it.

### Changing options from code

After you change the `<option>`s or set `select.value` in a script, call `refresh()` so the combobox reads them again.

```javascript
select.append(new Option('Fig', 'fig'))
tabler.Combobox.getInstance(select).refresh()
```

### Moving from Tom Select

| Tom Select | Combobox |
| --- | --- |
| `new TomSelect(select)` | `data-bs-toggle="combobox"` on the `<select>`, or `new tabler.Combobox(select)` |
| `dropdownParent: 'body'` | `data-bs-container="body"` |
| `maxItems` | `data-bs-max-items` |
| `data-placeholder` | Same attribute |
| `render.option` with `data-custom-properties` | `data-custom-properties`, no render function needed |
| `onChange` | The native `change` event on the `<select>` |
| `sync()` | `refresh()` |
| `create`, remote `load`, other plugins | Not supported yet |

## Form submission

When `data-bs-name` is set, a hidden `<input>` with that name is inserted before the toggle and updated on every change.

```html
<!-- What you write -->
<button class="form-select combobox-toggle" type="button" data-bs-toggle="combobox" data-bs-name="country">…</button>

<!-- What the script adds before the toggle -->
<input type="hidden" name="country" value="us" />
```

## JavaScript

### Initialization

The combobox initializes itself on every `[data-bs-toggle="combobox"]` on page load.

<CodeDocs name="combobox-init" file="core/js/src/combobox.ts" />

### Via data attributes

| Attribute | Description |
| --- | --- |
| `data-bs-toggle="combobox"` | Initializes the combobox on the toggle button. |
| `data-bs-value` | On a `.dropdown-item`, the value used when that item is selected. |

### Options

Pass options as `data-bs-*` attributes on the toggle, or as an object when creating the instance.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `multiple` | boolean | `false` | Allow several items; the menu stays open. |
| `name` | string \| null | `null` | Name of the hidden input used for form submission. |
| `placeholder` | string | `''` | Text shown while nothing is selected. |
| `search` | boolean \| null | `null` | `false` removes the search field on a `<select>`. Markup mode uses a search input when the menu has one. |
| `searchPlaceholder` | string | `'Search…'` | Placeholder of the generated search field. |
| `noResultsText` | string | `'No results found'` | Text of the generated empty message. |
| `searchNormalize` | boolean | `false` | Ignore accents when searching. |
| `maxItems` | number \| null | `null` | Most items a multiple select accepts. |
| `tagsOverflow` | `'count'` \| `'wrap'` | `'count'` | How a multiple `<select>` shows tags that do not fit: a `+N` tag, or extra lines. |
| `container` | string \| element | `null` | Where to append the menu, for example `'body'`. |
| `placement` | string \| null | `null` | Popper placement; `bottom-start` (`bottom-end` in RTL) when empty. |
| `offset` | array \| string | `[0, 2]` | Offset of the menu from the toggle. |
| `boundary` | string \| element | `'clippingParents'` | Overflow boundary of the menu. |

### Methods

| Method | Description |
| --- | --- |
| `toggle()` | Opens or closes the menu. |
| `show()` | Opens the menu. |
| `hide()` | Closes the menu. |
| `update()` | Repositions an open menu. |
| `refresh()` | Rebuilds the menu from the `<select>` and re-reads its value. |
| `dispose()` | Removes the instance and the hidden input. |
| `getInstance(element)` | Static. Returns the instance bound to the element, or `null`. |
| `getOrCreateInstance(element, config)` | Static. Returns the existing instance, or creates one. |

### Events

Events fire on the toggle button.

| Event | Description |
| --- | --- |
| `show.bs.combobox` | Fires when `show()` is called; can be cancelled. |
| `shown.bs.combobox` | Fires once the menu is visible. |
| `hide.bs.combobox` | Fires when `hide()` is called; can be cancelled. |
| `hidden.bs.combobox` | Fires once the menu is hidden. |
| `change.bs.combobox` | Fires when the selection changes. `event.value` holds the value (an array with `multiple`) and `event.item` the clicked item. |

## Accessibility

- The toggle gets `aria-haspopup="listbox"` and `aria-expanded`; the menu gets `role="listbox"` and each item `role="option"` with `aria-selected`.
- Keyboard: <kbd>↓</kbd> / <kbd>↑</kbd> open the menu and move between items, <kbd>Home</kbd> / <kbd>End</kbd> jump to the first or last item, <kbd>Enter</kbd> / <kbd>Space</kbd> select, <kbd>Esc</kbd> closes and returns focus to the toggle, <kbd>Tab</kbd> closes.
- Label the field with a visible `<label>` or `aria-label`, and give the search input an `aria-label`.
