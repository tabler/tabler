Every release that changes something you have to touch in your own code gets its own guide. Each guide starts with a table of the changes that can affect you, then shows a before and after example for every one of them.

Upgrade one version at a time. If you're on 1.4, read the 1.5 guide first, then the 1.6 guide. Releases before 1.5 didn't need a guide, updating the package was enough.

## Upgrade with a coding agent

The `tabler-upgrade` [agent skill](/ui/getting-started/llms#agent-skills) does the steps above for you. It finds the Tabler version in your project, reads every guide between it and the latest release, changes the affected code and lists what it changed and what is only deprecated. Add it with the [skills](https://skills.sh) CLI, then ask your agent to upgrade Tabler:

```shell
npx skills add tabler/tabler --skill tabler-upgrade
```

The complete list of changes in every release, including the ones that don't need any work on your side, is in the [changelog](https://github.com/tabler/tabler/blob/dev/core/CHANGELOG.md).
