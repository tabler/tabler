## What is Tabler?

Tabler is a UI kit for admin panels and dashboards, built on Bootstrap 5. It gives you [layouts](/ui/layout) and [components](/ui/components) that already work together, so you can pick the ones you need and adjust them to your design. It's responsive and works in every current browser.

## What are the benefits?

You don't have to build the common parts of an app interface from scratch. Cards, tables, forms, navigation and the page layouts are ready, and each of them has a dark mode and an RTL version. Tabler is open source under the MIT license and is developed on GitHub, so you can report a bug, send a fix or read the source of any component.
