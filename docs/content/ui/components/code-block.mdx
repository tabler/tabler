## Default markup

A `.code-block` wraps a `pre`. The copy button uses the [Clipboard](/ui/plugins/clipboard) plugin: `data-bs-target` points to the element with the code. Without a header, the button sits in the top right corner.

## Line numbers and highlighted lines

Add `.code-block-numbered` and put every line in a `.code-line`. Add `.code-line-highlight` to the lines you want to point out. Write the lines next to each other without line breaks between the tags.

    <span class="code-block-title">share.js</span>

    <svg xmlns="http://www.w3.org/2000/svg" class="icon clipboard-feedback" width="24" height="24" viewBox="0 0 24 24" stroke-width="2" stroke="currentColor" fill="none" stroke-linecap="round" stroke-linejoin="round"><path stroke="none" d="M0 0h24v24H0z" fill="none"/><path d="M5 12l5 5l10 -10"/></svg>

## Without copy button

Leave out the `.code-block-copy` button for a plain block.

<Example>
<div class="code-block">
  <pre><code>npm install @tabler/core</code></pre>
</div>
</Example>

## Syntax highlighting

The code block does not highlight syntax. Put the output of a highlighter, such as Prism or Shiki, inside the `code` element. The copy button reads the text, so the markup of the highlighter does not end up in the clipboard.

## Component

In Astro, use the `CodeBlock` component. It takes the code as a prop and renders the lines, the header and the copy button.

```astro
<CodeBlock code={code} title="share.js" language="JavaScript" numbered highlight={[3, 4]} />
```
