## Default markup

A `.mockup-browser` has a `.mockup-browser-toolbar` with the window dots and an address bar, and a `.mockup-browser-body` with the page. An image in the body fills the width of the frame.

<Example>
<div class="mockup-browser">
  <div class="mockup-browser-toolbar">
    <span class="mockup-browser-controls"></span>
    <div class="mockup-browser-url"><span>preview.tabler.io</span></div>
  </div>
  <div class="mockup-browser-body">
    <img src="/static/tabler-preview.png" srcset="/static/tabler-preview.png 1x, /static/tabler-preview@2x.png 2x" class="hide-theme-dark" alt="Tabler dashboard" />
    <img src="/static/tabler-preview-dark.png" srcset="/static/tabler-preview-dark.png 1x, /static/tabler-preview-dark@2x.png 2x" class="hide-theme-light" alt="Tabler dashboard" />
  </div>
</div>
</Example>

## Secure address

Put an icon before the address text to show a secure page. The icon is scaled down to match the text.

<Example>
<div class="mockup-browser">
  <div class="mockup-browser-toolbar">
    <span class="mockup-browser-controls"></span>
    <div class="mockup-browser-url"><Icon name="lock" /><span>https://preview.tabler.io</span></div>
  </div>

    <img src="/static/tabler-preview.png" srcset="/static/tabler-preview.png 1x, /static/tabler-preview@2x.png 2x" class="hide-theme-dark" alt="Tabler dashboard" />

</Example>

## Any content

The body takes any markup, not only an image. Add a padding utility to the body when the content needs space from the frame.

<Example>
<div class="mockup-browser">
  <div class="mockup-browser-toolbar">
    <span class="mockup-browser-controls"></span>
    <div class="mockup-browser-url"><Icon name="lock" /><span>example.com/signup</span></div>
  </div>
  <div class="mockup-browser-body p-4">
    <h3 class="card-title">Create an account</h3>
    <div class="mb-3">
      <label class="form-label" for="mockup-browser-email">Email</label>
      <input type="email" class="form-control" id="mockup-browser-email" placeholder="you@example.com" />
    </div>
    <button type="button" class="btn btn-primary w-100">Sign up</button>
  </div>
</div>
</Example>

## Custom look

Set the `--tblr-mockup-browser-*` variables on the frame to change the colors, the shadow or the size of the dots. The three dots have their own color variables, `--tblr-mockup-browser-control-color-1` to `-3`.

<Example>
<div class="mockup-browser" style="--tblr-mockup-browser-toolbar-bg: var(--tblr-gray-900); --tblr-mockup-browser-toolbar-color: var(--tblr-gray-400); --tblr-mockup-browser-border-color: var(--tblr-gray-900); --tblr-mockup-browser-box-shadow: none">
  <div class="mockup-browser-toolbar">
    <span class="mockup-browser-controls"></span>
    <div class="mockup-browser-url"><Icon name="lock" /><span>preview.tabler.io</span></div>
  </div>
  <div class="mockup-browser-body">
    <img src="/static/tabler-preview-dark.png" srcset="/static/tabler-preview-dark.png 1x, /static/tabler-preview-dark@2x.png 2x" alt="Tabler dashboard" />
  </div>
</div>
</Example>

## Accessibility

- The window dots are decoration. They are an empty element, so screen readers skip them.
- The address bar is plain text and is read as such. It is not a link and not a form field.
- Give a screenshot in the body an `alt` text that says what page it shows.
