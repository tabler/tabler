## Overview

A nav with many links wraps to a second line, or runs out of its container, when the screen gets narrow. Nav overflow keeps the nav on one line. Items that do not fit move into a More dropdown at the end of the nav, and come back when there is room again. This is also known as the Priority+ pattern.

Wrap the `.nav` in a `.nav-overflow` element and add `data-bs-toggle="nav-overflow"` to the wrapper. Resize the window to see the items move.

<Example overflow="visible">
<div class="nav-overflow" data-bs-toggle="nav-overflow">
  <ul class="nav nav-pills">
    <li class="nav-item"><a class="nav-link active" aria-current="page" href="#">Home</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Dashboard</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Products</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Services</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Analytics</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Reports</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Settings</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Help</a></li>
  </ul>
</div>
</Example>

How it works:

- The component watches the size of the wrapper, not of the window. It works in a card, a sidebar or any container that changes width.
- It measures the wrapper, not the nav. Moving items changes the width of the nav, so measuring the nav would feed the result back in.
- Moved items are copied into the menu as `.dropdown-item`, and the originals are hidden. The `.active` and `.disabled` states are copied too.
- It works with every nav style: plain, `.nav-pills`, `.nav-tabs` and `.nav-underline`.

## Keep items visible

Add `.nav-overflow-keep` to an item that must never move to the menu, such as the home link or a call to action. The other items move first.

## With dropdowns

A nav item that has its own dropdown becomes a nested `.dropend` in the More menu. The component moves the original `.dropdown-menu` instead of copying it, so its ids and content stay the same, and moves it back when the item fits again.

<Example overflow="visible">
<div class="nav-overflow" data-bs-toggle="nav-overflow">
  <ul class="nav nav-pills">
    <li class="nav-item"><a class="nav-link active" aria-current="page" href="#">Home</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Dashboard</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Services</a></li>
    <li class="nav-item dropdown">
      <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown" role="button" aria-expanded="false">Products</a>
      <div class="dropdown-menu">
        <a class="dropdown-item" href="#">Laptops</a>
        <a class="dropdown-item" href="#">Phones</a>
        <a class="dropdown-item" href="#">Tablets</a>
      </div>
    </li>
    <li class="nav-item dropdown">
      <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown" role="button" aria-expanded="false">Company</a>
      <div class="dropdown-menu">
        <a class="dropdown-item" href="#">About</a>

## Customizing the toggle

### Text and icon

Change the text with `data-bs-more-text`. Set it to `false` for an icon-only toggle. The button then gets `aria-label="More"`, so it still has a name.

<Example overflow="visible">
<div class="nav-overflow" data-bs-toggle="nav-overflow" data-bs-more-text="false">
  <ul class="nav nav-pills">
    <li class="nav-item"><a class="nav-link active" aria-current="page" href="#">Home</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Dashboard</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Products</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Services</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Analytics</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Reports</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Settings</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Help</a></li>
  </ul>
</div>
</Example>

To use another icon, put an element with `data-bs-overflow-icon` inside the wrapper, next to the nav. The component uses it as the toggle icon and removes the original. The icon markup is sanitized first.

```html
<div class="nav-overflow" data-bs-toggle="nav-overflow">
  <ul class="nav">…</ul>
  <svg data-bs-overflow-icon xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="icon">
    <path d="M4 6l16 0" /><path d="M4 12l16 0" /><path d="M4 18l16 0" />
  </svg>
</div>
```

### Your own toggle

To change the markup or the label of the button, write the toggle yourself. The component uses a `.nav-overflow-toggle` it finds in the wrapper instead of creating one:

```html
<div class="nav-overflow" data-bs-toggle="nav-overflow">
  <ul class="nav nav-pills">
    <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
    …
    <li class="nav-item dropdown nav-overflow-item">
      <button class="nav-link nav-overflow-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false" aria-label="Show more links">…</button>
      <div class="dropdown-menu dropdown-menu-end nav-overflow-menu"></div>
    </li>
  </ul>
</div>
```

## Collapse all

Use `data-bs-collapse-below` to move every item into the menu when the wrapper is narrower than a breakpoint. Pass a breakpoint name, read from `--tblr-breakpoint-{name}`, or a number of pixels. Above that width the nav collapses item by item again. Items with `.nav-overflow-keep` stay visible.

```html
<div class="nav-overflow" data-bs-toggle="nav-overflow" data-bs-collapse-below="md">…</div>
```

## Options

Pass options as data attributes on the wrapper, or in the config object.

| Option | Default | Description |
| --- | --- | --- |
| `collapseBelow` | `0` | Wrapper width below which every item moves to the menu. A breakpoint name (`md`) or a number of pixels. `0` turns it off. |
| `iconPlacement` | `'start'` | Puts the icon before (`start`) or after (`end`) the text. |
| `menuPlacement` | `'bottom-end'` | Where the menu opens: `bottom-end`, `bottom-start`, `top-end` or `top-start`. |
| `menuStrategy` | `'absolute'` | Positioning strategy of the menu. Use `fixed` when a parent with `overflow` clips it. |
| `moreText` | `'More'` | Text of the toggle, inserted as plain text. `false` or an empty string gives an icon-only toggle. |
| `moreIcon` | three dots | SVG or HTML of the toggle icon. It is sanitized before insertion. |
| `threshold` | `0` | Minimum number of items that stay visible. |

## JavaScript

On page load Tabler creates a `NavOverflow` for every element with `data-bs-toggle="nav-overflow"`. This is the code that runs:

<CodeDocs name="nav-overflow-init" file="core/js/src/bootstrap/nav-overflow.ts" />

Create it yourself for a nav added later, and pass the wrapper, not the nav:

```js
const navOverflow = new tabler.NavOverflow(document.querySelector('.nav-overflow'), {
  moreText: 'See all',
  threshold: 2,
});
```

| Method | Description |
| --- | --- |
| `update()` | Works out again which items fit. It runs by itself when the wrapper changes size. |
| `dispose()` | Puts every item back, removes the generated toggle and stops watching the wrapper. |
| `getInstance(element)` | Static. Returns the component for the wrapper, or `null`. |
| `getOrCreateInstance(element, config)` | Static. Returns the component for the wrapper and creates it when needed. |

Both events fire on the wrapper:

| Event | Description |
| --- | --- |
| `update.bs.navoverflow` | Fires after `update()`. |
| `overflow.bs.navoverflow` | Fires when items move to the menu. The event carries `overflowCount` and `visibleCount`. |

```js
document.querySelector('.nav-overflow').addEventListener('overflow.bs.navoverflow', (event) => {
  console.log(`${event.overflowCount} items in the menu, ${event.visibleCount} visible`);
});
```

## Accessibility

- The More toggle is a `<button>` with `aria-expanded`, and the menu works with the keyboard like any other dropdown.
- An icon-only toggle is named `More` with `aria-label`. For a page in another language, set `moreText` or write your own toggle with a translated `aria-label`.
- A moved dropdown gets `role="button"` and `tabindex="0"` in the menu, so it can be reached with the keyboard.
