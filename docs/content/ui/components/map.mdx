## Overview

The map component turns an element into an interactive map. Add `data-bs-toggle="map"` to it, set the center and the zoom with data attributes, and write the markers as child elements. No script is needed.

The map is drawn by [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/), an open-source map library, which you load next to Tabler. The map tiles come from [OpenFreeMap](https://openfreemap.org/). It needs no account and no access token, and it can be used in commercial projects.

If you only need a simple map of countries or regions, use the [vector map](/ui/plugins/vector-map) instead. It makes no network calls at all.

## Installation

MapLibre GL JS is published as an ES module. Tabler uses version 6. Load the stylesheet, then import the library in a module script, before the Tabler script:

<Code
	lang="html"
	code={`<link rel="stylesheet" href="${site.cdnUrl}/dist/libs/maplibre-gl/dist/maplibre-gl.css" />
<script type="module">
  import * as maplibregl from '${site.cdnUrl}/dist/libs/maplibre-gl/dist/maplibre-gl.mjs'

  // The map component looks for the library here
  window.maplibregl = maplibregl
</script>
<script src="${site.cdnUrl}/dist/js/tabler.min.js" defer></script>`}
/>

The library loads two more files from the same folder, `maplibre-gl-shared.mjs` and `maplibre-gl-worker.mjs`, so keep the three together when you host them yourself.

With a bundler, install the package and set the global before you import Tabler:

```bash
npm install maplibre-gl
```

```js
import * as maplibregl from 'maplibre-gl'
import 'maplibre-gl/dist/maplibre-gl.css'

window.maplibregl = maplibregl
```

<Danger title="Use version 6.4.1 or newer">
  Older versions, including all of version 5, have a known security issue in the code that cleans the attribution text.
</Danger>

Browsers do not load ES modules from a page opened straight from the disk. Use a local server to see the maps while you work.

Tabler styles the map controls, popups and attribution to match the interface, in light and dark mode. These styles are in `tabler-vendors.css`, so load it after the MapLibre stylesheet:

<Code
	lang="html"
	code={`<link rel="stylesheet" href="${site.cdnUrl}/dist/css/tabler-vendors.min.css" />`}
/>

## Usage

### Basic map

Put the map element inside a `ratio` element, so the map keeps its shape on every screen size. `data-bs-center` takes the longitude first and the latitude second. This is the opposite of what most map services show.

<Example flush>
<Map rounded={false} mapId="simple" />
</Example>

Change the shape with the ratio classes, for example `ratio-21x9` for a wide map or `ratio-1x1` for a square one. Add `data-bs-controls="true"` for the zoom and compass buttons.

### Map styles

The map uses a light gray style in light mode and a dark one in dark mode. Tabler softens their colors, so markers and data stand out. Set another style with `data-bs-map-style`: the name of an OpenFreeMap style, or the URL of any MapLibre style.

| Style | Result |
| --- | --- |
| `positron` | Light gray map. The default in light mode. |
| `dark` | Dark gray map. The default in dark mode. |
| `liberty` | Street map in color. |
| `bright` | Street map with stronger colors. |
| `fiord` | Dark blue map. |

<Example flush>
<Map rounded={false} mapId="light" />
</Example>

`data-bs-map-style-dark` sets the style for dark mode. Styles from other providers work the same way, as long as they follow the MapLibre style format. Check the terms of each provider, as many of them need an API key or a paid plan.

### Dark mode

The map follows the nearest `data-bs-theme` and changes its style when the theme changes. Markers and popups stay on the map. To keep one look in both modes, set `data-bs-map-theme` to `light` or `dark`.

### Markers

Each child element with `data-bs-lng` and `data-bs-lat` becomes a marker. Use the `.map-marker` class to draw it: a circle in the primary color that can hold an icon, a short count or an avatar. Put a `.map-marker-label` element inside the marker for a short text under it.

Add `.map-marker-dot` for a small dot, or `.map-marker-pin` for a pin that points down. A pin needs `data-bs-anchor="bottom"`, so its tip sits on the place. Change the color with `.map-marker-{color}`.

<Example flush>
<Map rounded={false} mapId="marker-styles" title="Marker styles" center={[52.522, 13.405]} zoom={11}>
  <span class="map-marker map-marker-dot" data-bs-lng="13.345" data-bs-lat="52.54"></span>
  <span class="map-marker map-marker-dot map-marker-red" data-bs-lng="13.39" data-bs-lat="52.545"></span>
  <span class="map-marker" data-bs-lng="13.445" data-bs-lat="52.538"><Icon name="building-store" /><span class="map-marker-label">Store</span></span>
  <span class="map-marker map-marker-green" data-bs-lng="13.35" data-bs-lat="52.512">12</span>
  <span class="map-marker map-marker-pin" data-bs-lng="13.405" data-bs-lat="52.522" data-bs-anchor="bottom"><Icon name="home" /></span>
  <span class="map-marker map-marker-pin map-marker-red" data-bs-lng="13.47" data-bs-lat="52.518" data-bs-anchor="bottom"><Icon name="star" /></span>
  <span class="map-marker" data-bs-lng="13.43" data-bs-lat="52.508"><span class="avatar avatar-sm" style="background-image: url(/static/avatars/000m.jpg)"></span></span>
</Map>
</Example>

Add `data-bs-draggable="true"` to let people move a marker, for example to pick an address.

HTML markers work well for up to a few hundred places. For more, use [clusters](#clusters).

### Popups

Add `data-bs-popup` to a marker for a short text that opens when the marker is clicked. Tabler draws the popup as a small bordered panel with no arrow.

<Example flush>
<Map rounded={false} mapId="markers" />
</Example>

For richer content, put a `<template>` inside the marker. Its content becomes the popup. Add the `map-popup-card` class to the template for a popup with an image: it removes the padding and sets a fixed width, so the image reaches the edges. `data-bs-close-button="true"` on the template adds a close button, and `data-bs-popup-open="true"` on the marker opens the popup from the start.

<Example flush>
<Map rounded={false} mapId="popup-card" title="Popup card" center={[52.546, 13.4]} zoom={11} ratio="4x3">
  <span class="map-marker map-marker-pin" data-bs-lng="13.4019" data-bs-lat="52.5169" data-bs-anchor="bottom" data-bs-popup-open="true">
    <Icon name="map-pin" />
    <template class="map-popup-card" data-bs-close-button="true">
      <div class="img-responsive img-responsive-21x9" style="background-image: url(/static/photos/a-visit-to-the-bookstore.jpg)"></div>
      <div class="p-3">
        <div class="fw-medium">Museum Island</div>
        <div class="text-secondary mb-3">Five museums on the Spree, open daily.</div>
        <a href="#" class="btn btn-primary btn-sm">View details</a>
      </div>
    </template>
  </span>
</Map>
</Example>

### Globe

Add `data-bs-globe="true"` to draw the map as a 3D globe. Use a low zoom, between 1 and 2, to see the whole globe. People can turn it by dragging.

```html
<div class="w-100 h-100" data-bs-toggle="map" data-bs-center="62,32" data-bs-zoom="1.3" data-bs-globe="true"></div>
```

### Content over the map

To put buttons or a small card over the map, place them next to the map element and position them with the utility classes:

```html
<div class="ratio ratio-16x9">
  <div>
    <div class="w-100 h-100 rounded" data-bs-toggle="map" data-bs-center="13.405,52.52" data-bs-zoom="10"></div>
    <div class="btn-list position-absolute top-0 start-0 m-2">
      <button type="button" class="btn btn-sm btn-pill btn-primary">Berlin</button>
      <button type="button" class="btn btn-sm btn-pill">Tokyo</button>
    </div>
  </div>
</div>
```

### Attribution

MapLibre adds the credit for the map data in the corner of the map. OpenFreeMap requires it, so do not hide it.

## Layers

Lines, areas and large sets of points are drawn as map layers. For these, take the MapLibre map from the component and use its own API. The `map` property is the [MapLibre map](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/).

A layer reads its data from a GeoJSON source. Layers are part of the map style, so add them in the `style.load` event. It runs when the map starts and again each time the style changes, for example on a theme change.

```js
document.addEventListener('DOMContentLoaded', function () {
  const map = tabler.MapView.getInstance('#map-route').map

  map.on('style.load', function () {
    map.addSource('route', {
      type: 'geojson',
      data: { type: 'Feature', geometry: { type: 'LineString', coordinates: [[13.3695, 52.5251], [13.4132, 52.5219], [13.4397, 52.505]] } },
    })
    map.addLayer({
      id: 'route',
      type: 'line',
      source: 'route',
      layout: { 'line-cap': 'round', 'line-join': 'round' },
      paint: { 'line-color': tabler.MapView.color('--tblr-primary'), 'line-width': 3 },
    })
  })
})
```

For an area, use a `Polygon` geometry with a `fill` layer, and a `line` layer for its outline.

### Theme colors in layers

MapLibre draws layers on a canvas, so a CSS variable does not work in `paint`, and neither do the `oklch()` values Tabler colors are written in. `MapView.color()` turns a variable, or any CSS color, into a plain `rgb()` color. Call it inside `style.load`, so the colors are read again after a theme change.

```js
tabler.MapView.color('--tblr-primary') // 'rgb(6, 111, 209)'
```

### Clusters

Put many points in a GeoJSON source with `cluster: true`. MapLibre then groups nearby points and splits the groups as you zoom in.

```js
map.addSource('stores', { type: 'geojson', data: stores, cluster: true, clusterRadius: 40 })

// Circle for each cluster, larger for more points
map.addLayer({
  id: 'clusters',
  type: 'circle',
  source: 'stores',
  filter: ['has', 'point_count'],
  paint: { 'circle-color': tabler.MapView.color('--tblr-primary'), 'circle-radius': ['step', ['get', 'point_count'], 14, 10, 18, 25, 24] },
})

// Number of points in the cluster
map.addLayer({
  id: 'cluster-count',
  type: 'symbol',
  source: 'stores',
  filter: ['has', 'point_count'],
  layout: { 'text-field': ['get', 'point_count_abbreviated'], 'text-font': ['Noto Sans Regular'], 'text-size': 12 },
  paint: { 'text-color': '#ffffff' },
})
```

`text-font` has to be a font the map style provides. All OpenFreeMap styles have `Noto Sans Regular`.

### Tooltips

For a short label on hover, add the `map-tooltip` class to a MapLibre popup. It turns the popup into a small dark label.

```js
const tooltip = new maplibregl.Popup({ closeButton: false, offset: 12, className: 'map-tooltip' })

map.on('mousemove', 'cities', function (event) {
  tooltip.setLngLat(event.lngLat).setText(event.features[0].properties.name).addTo(map)
})
map.on('mouseleave', 'cities', function () {
  tooltip.remove()
})
```

Live versions of a route, an area, clusters, a bubble map, a globe with arcs and a city switcher are on the [maps preview page](https://preview.tabler.io/maps.html). The [map blocks page](https://preview.tabler.io/map-blocks.html) has larger examples: a store locator, a delivery tracker, a map of live users and a vector map of users by country.

### Via JavaScript

Create a map from your own code with the same options:

```js
const view = new tabler.MapView('#map', {
  center: [13.405, 52.52],
  zoom: 12,
  controls: true,
})
```

### Options

Pass options as data attributes, with the name written in kebab case after `data-bs-`, or in the config object.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `center` | array, string | `[0, 0]` | Center of the map: `[longitude, latitude]`, or the two numbers in a string such as `"13.405,52.52"`. |
| `zoom` | number | `1` | Zoom level, from 0 for the whole world to about 20 for a building. |
| `mapStyle` | string | `'positron'` | Name of an OpenFreeMap style, or the URL of a MapLibre style. |
| `mapStyleDark` | string | `'dark'` | Style used in dark mode. Set `null` to keep `mapStyle` in both modes. |
| `mapTheme` | string | `'auto'` | `'auto'` follows the nearest `[data-bs-theme]`; `'light'` or `'dark'` keeps one look. |
| `palette` | boolean | `true` | Softer colors for the `positron` and `dark` styles. Other styles are left as they are. |
| `controls` | boolean | `false` | Show the zoom and compass buttons. |
| `globe` | boolean | `false` | Draw the map as a 3D globe. |
| `mapOptions` | object | `{}` | Any [MapLibre map option](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/), passed straight through. |

A marker element takes these attributes:

| Attribute | Description |
| --- | --- |
| `data-bs-lng`, `data-bs-lat` | Position of the marker. Both are needed. |
| `data-bs-anchor` | Part of the marker that sits on the position: `center` by default, `bottom` for a pin. |
| `data-bs-draggable` | Set `true` to let people move the marker. |
| `data-bs-popup` | Text of a popup that opens when the marker is clicked. |
| `data-bs-popup-open` | Set `true` to open the popup from the start. |

### Methods

| Name | Description |
| --- | --- |
| `map` | The MapLibre map, for layers, events and everything else the options do not cover. |
| `markers` | The MapLibre markers made from the child elements, in document order. |
| `dispose()` | Removes the map, its markers and the instance. |
| `MapView.color(value)` | Turns a CSS variable or color into a plain `rgb()` color for a map layer. |
| `MapView.getInstance(element)` | Returns the instance for an element, or `null`. |
| `MapView.getOrCreateInstance(element)` | Returns the instance, or creates one. |

### Events

| Event | Description |
| --- | --- |
| `load.bs.map` | Fires on the map element once the map has loaded its style and first tiles. |

## Using Mapbox GL JS

MapLibre GL JS started as a fork of Mapbox GL JS, so the two share most of their API. The map component works with MapLibre only. To use Mapbox, write the map script yourself: load its script and stylesheet, set `mapboxgl.accessToken` to your public token, and use a `mapbox://` style URL.

## Accessibility

- The map is a picture for most users. Give the same information as text near it, for example the address or a list of places.
- Add `role="region"` and an `aria-label` to the map element, so screen reader users know what the map shows.
- Do not put an action only on a marker. Repeat it in a normal link or button below the map.
- Keep a visible fallback when the script fails to load, for example the address in text.
