## Overview

The map is a small wrapper around [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/), an open-source map library. Tabler gives you the container markup and a short init script. MapLibre draws the tiles, handles zoom, and renders the markers.

The demos load their map tiles from [OpenFreeMap](https://openfreemap.org/). It needs no account and no access token, and it can be used in commercial projects. If you only need a simple map of countries or regions, use the [vector map](/ui/plugins/vector-map) instead. It makes no network calls at all.

## Installation

Install MapLibre GL JS with npm. Tabler uses version 5, the last one that ships a classic script file:

```bash
npm install maplibre-gl@5
```

Or include it from a CDN. You need two files: the stylesheet and the library.

<Code
	lang="html"
	code={`<link rel="stylesheet" href="${site.cdnUrl}/dist/libs/maplibre-gl/dist/maplibre-gl.css" />
<script src="${site.cdnUrl}/dist/libs/maplibre-gl/dist/maplibre-gl.js"></script>`}
/>

Tabler styles the map controls, popups and attribution to match the interface, in light and dark mode. These styles are in `tabler-vendors.css`, so load it after the MapLibre stylesheet:

<Code
	lang="html"
	code={`<link rel="stylesheet" href="${site.cdnUrl}/dist/css/tabler-vendors.min.css" />`}
/>

## Usage

### Markup

Put the map container inside a `ratio` element, so the map keeps its shape on every screen size. Give the inner element an `id` and the `w-100 h-100` classes.

<Example codeOnly>
<div class="ratio ratio-16x9">
  <div><div id="map-simple" class="w-100 h-100"></div></div>
</div>
</Example>

Change the shape with the ratio classes, for example `ratio-21x9` for a wide map or `ratio-1x1` for a square one.

### Init the map

Create the map after the DOM is ready. Pass the id of your container, a style, a zoom level, and a center point.

```js
document.addEventListener('DOMContentLoaded', function () {
  const map = new maplibregl.Map({
    container: 'map-simple',
    style: 'https://tiles.openfreemap.org/styles/liberty',
    zoom: 13,
    center: [13.4049, 52.518827],
  })
})
```

<Example>
<Map mapId="simple" />
</Example>

`center` takes the longitude first and the latitude second. This is the opposite of what most map services show.

### Map styles

Set `style` to the URL of any MapLibre style. OpenFreeMap has five of them:

| Style | Result |
| --- | --- |
| `https://tiles.openfreemap.org/styles/liberty` | Default street map. |
| `https://tiles.openfreemap.org/styles/bright` | Street map with stronger colors. |
| `https://tiles.openfreemap.org/styles/positron` | Light gray map, good under charts and markers. |
| `https://tiles.openfreemap.org/styles/dark` | Dark map. |
| `https://tiles.openfreemap.org/styles/fiord` | Dark blue map. |

<Example>
<Map mapId="light" />
</Example>

Styles from other providers work the same way, as long as they follow the MapLibre style format. Check the terms of each provider, as many of them need an API key or a paid plan.

### Markers

Add a marker for each place. `setLngLat` takes the same longitude and latitude order as `center`.

```js
const cities = [
  [-58.666667, -34.58333333], // Buenos Aires
  [16.366667, 48.2], // Vienna
  [116.383333, 39.91666667], // Beijing
]

cities.forEach(function (coords) {
  new maplibregl.Marker({ color: 'var(--tblr-primary)' }).setLngLat(coords).addTo(map)
})
```

<Example>
<Map mapId="markers" />
</Example>

The `color` option is written to the `fill` attribute of the marker icon. A CSS variable works there, so `var(--tblr-primary)` keeps the markers in your theme color, including after a theme change.

### Custom markers

To draw a marker in HTML, create an element with the `.map-marker` class and pass it as `element`. The marker is a circle in the primary color. Put an icon, a short count or an avatar inside it.

```js
const element = document.createElement('span')
element.className = 'map-marker map-marker-green'
element.textContent = '12'

new maplibregl.Marker({ element: element }).setLngLat([13.35, 52.512]).addTo(map)
```

Add `.map-marker-dot` for a small dot, or `.map-marker-pin` for a pin that points down. A pin needs `anchor: 'bottom'`, so its tip sits on the place. Change the color with `.map-marker-{color}`.

```js
const pin = document.createElement('span')
pin.className = 'map-marker map-marker-pin map-marker-red'

new maplibregl.Marker({ element: pin, anchor: 'bottom' }).setLngLat([13.47, 52.518]).addTo(map)
```

You can also write the markers in the page and move them to the map. The preview pages do this: each marker sits in a hidden element with `data-lng` and `data-lat`, and a short loop passes it to MapLibre.

```html
<div id="map-markers" hidden>
  <div data-lng="13.405" data-lat="52.522">
    <span class="map-marker map-marker-pin">...</span>
  </div>
</div>
```

```js
document.querySelectorAll('#map-markers > [data-lng]').forEach(function (item) {
  new maplibregl.Marker({ element: item.firstElementChild, anchor: 'bottom' })
    .setLngLat([Number(item.dataset.lng), Number(item.dataset.lat)])
    .addTo(map)
})
```

### Draggable markers

Pass `draggable: true` to let people move a marker, for example to pick an address. Read the new position in the `dragend` event.

```js
const marker = new maplibregl.Marker({ element: pin, anchor: 'bottom', draggable: true }).setLngLat([13.405, 52.52]).addTo(map)

marker.on('dragend', function () {
  console.log(marker.getLngLat())
})
```

### Popups

Attach a popup to a marker with `setPopup`. It opens when the marker is clicked. Click a marker on the map above to see one.

```js
new maplibregl.Marker({ color: 'var(--tblr-primary)' })
  .setLngLat([16.366667, 48.2])
  .setPopup(new maplibregl.Popup({ offset: 32 }).setText('Vienna'))
  .addTo(map)
```

Use `setHTML` instead of `setText` for richer content. Only pass HTML you trust, as it is not escaped.

### Popup card

For a popup with an image, add the `map-popup-card` class with the `className` option. It removes the padding and sets a fixed width, so the image reaches the edges. Keep the content in a `<template>` and pass it with `setDOMContent`.

```html
<template id="popup-museum">
  <div class="img-responsive img-responsive-21x9" style="background-image: url(...)"></div>
  <div class="p-3">
    <div class="fw-medium">Museum Island</div>
    <div class="text-secondary mb-3">Five museums on the Spree, open daily.</div>
    <a href="#" class="btn btn-primary btn-sm">View details</a>
  </div>
</template>
```

```js
const popup = new maplibregl.Popup({ offset: 40, className: 'map-popup-card', maxWidth: 'none' })
  .setDOMContent(document.getElementById('popup-museum').content)

new maplibregl.Marker({ element: pin, anchor: 'bottom' }).setLngLat([13.4019, 52.5169]).setPopup(popup).addTo(map)
```

### Controls

Add the zoom and compass buttons with `NavigationControl`. They go to the top right corner by default.

```js
map.addControl(new maplibregl.NavigationControl())
```

MapLibre also has `FullscreenControl`, `GeolocateControl` and `ScaleControl`. Pass a corner as the second argument, for example `'bottom-left'`.

### Dark mode

A map style does not change with the page theme on its own. Pick the style from the `data-bs-theme` attribute, and set it again when the attribute changes:

```js
const themeStyle = function () {
  const dark = document.documentElement.getAttribute('data-bs-theme') === 'dark'
  return 'https://tiles.openfreemap.org/styles/' + (dark ? 'dark' : 'liberty')
}

const map = new maplibregl.Map({
  container: 'map-simple',
  style: themeStyle(),
  zoom: 13,
  center: [13.4049, 52.518827],
})

new MutationObserver(function () {
  map.setStyle(themeStyle())
}).observe(document.documentElement, { attributeFilter: ['data-bs-theme'] })
```

Markers and popups stay on the map when the style changes. The maps on this page follow the theme this way.

### Attribution

MapLibre adds the credit for the map data in the corner of the map. OpenFreeMap requires it, so do not hide it.

## Using Mapbox GL JS

MapLibre GL JS started as a fork of Mapbox GL JS, so the two share most of their API. To use Mapbox instead, load its script and stylesheet, replace `maplibregl` with `mapboxgl`, set `mapboxgl.accessToken` to your public token, and use a `mapbox://` style URL.

## Accessibility

- The map is a picture for most users. Give the same information as text near it, for example the address or a list of places.
- Add an `aria-label` to the map container, so screen reader users know what the map shows.
- Do not put an action only on a marker. Repeat it in a normal link or button below the map.
- Keep a visible fallback when the script fails to load, for example the address in text.
