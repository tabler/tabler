## Sizes

Use `.shadow-xs`, `.shadow-sm`, `.shadow`, `.shadow-lg`, or `.shadow-xl` to add a shadow, and `.shadow-none` to remove one. Each class uses a `--tblr-box-shadow-*` custom property, which gets darker in the dark theme so the shadow stays visible.

<Example centered>
<div class="p-3 bg-surface rounded shadow-xs">xs</div>
<div class="p-3 bg-surface rounded shadow-sm">sm</div>
<div class="p-3 bg-surface rounded shadow">default</div>
<div class="p-3 bg-surface rounded shadow-lg">lg</div>
<div class="p-3 bg-surface rounded shadow-xl">xl</div>
</Example>

## Accessibility

- A shadow is decoration. Do not use it as the only sign of a state, such as a selected card. Add a border, a color, or a text label too.
