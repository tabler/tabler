Use these classes on an element with `.d-grid` to align all its items inside their grid cells. Choose from `start`, `end`, `center`, `baseline`, and `stretch` (the default).

## Justify items

`.justify-items-*` aligns the items along the inline (horizontal) axis of each cell.

<Example>
<div class="d-grid justify-items-center gap-2 p-2 border rounded" style="grid-template-columns: repeat(3, 1fr)">
  <div class="p-2 bg-primary-lt rounded">One</div>
  <div class="p-2 bg-primary-lt rounded">Two</div>
  <div class="p-2 bg-primary-lt rounded">Three</div>
</div>
</Example>

## Place items

`.place-items-*` sets `align-items` and `justify-items` together, so `.place-items-center` centers each item on both axes.

<Example>
<div class="d-grid place-items-center gap-2 p-2 border rounded" style="grid-template-columns: repeat(3, 1fr); grid-auto-rows: 6rem">
  <div class="p-2 bg-primary-lt rounded">One</div>
  <div class="p-2 bg-primary-lt rounded">Two</div>
  <div class="p-2 bg-primary-lt rounded">Three</div>
</div>
</Example>

## Responsive

All classes have responsive variants, for example `.justify-items-md-start` or `.place-items-lg-center`.

```html
<div class="d-grid place-items-center place-items-md-start">...</div>
```

## Accessibility

- Alignment moves items visually, not in the reading order. Screen readers and keyboard focus still follow the order in the markup.
- `justify-items` has no effect on a flex container. Use `justify-content` there instead.
