## Overview

A scroll container gives no hint that it holds more content. Add a `scroll-shadow` class to the element that scrolls, and its edges fade out while there is more to scroll in that direction:

- at the top of a list only the bottom edge fades,
- in the middle both edges fade,
- at the end only the top edge fades.

A container that does not overflow shows no fade at all. The effect is pure CSS: no JavaScript and no extra markup.

## Usage

Put the class on the element that has the scrollbar. It works with `scrollable`, `scroll-y`, `scroll-x`, `card-body-scrollable`, `dropdown-menu-scrollable`, `table-responsive` and any element with `overflow: auto`.

| Class             | Fades                                          |
| ----------------- | ---------------------------------------------- |
| `scroll-shadow`   | Every edge that has more content, on both axes |
| `scroll-shadow-y` | Top and bottom only                            |
| `scroll-shadow-x` | Start and end only                             |

### Scrollable card body

Scroll the list to see the top and bottom edges change.

  <div class="card-header">
    <h3 class="card-title">Notifications</h3>

### Both axes

`scroll-shadow` fades whichever axis overflows. Here the box scrolls in both directions.

<Example centered>
<div class="scroll-shadow border rounded" style="width: 20rem; height: 12rem; overflow: auto" tabindex="0">
  <div class="p-3" style="width: 36rem">
    <p>This box is wider and taller than its frame. Scroll it in any direction and the edges with more content fade out.</p>
    <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Integer posuere erat a ante venenatis dapibus posuere velit aliquet.</p>
    <p>Donec ullamcorper nulla non metus auctor fringilla. Cras mattis consectetur purus sit amet fermentum.</p>
    <p class="mb-0">Maecenas faucibus mollis interdum. Nullam quis risus eget urna mollis ornare vel eu leo.</p>
  </div>
</div>
</Example>

### Sticky headers

The top fade covers the first `--tblr-scroll-shadow-size` of the container, so it would also fade a sticky table header. Set `--tblr-scroll-shadow-offset-top` to the height of the header, and the fade starts below it.

```html
<div class="table-responsive scroll-shadow-y" style="max-height: 20rem; --tblr-scroll-shadow-offset-top: 2.5rem">
  <table class="table">
    <thead class="sticky-top">
      ...
    </thead>
    ...
  </table>
</div>
```

## Custom properties

Set these on the element, with a `style` attribute or a class, to change one container.

| Property                          | Default  | Description                                                |
| --------------------------------- | -------- | ---------------------------------------------------------- |
| `--tblr-scroll-shadow-size`       | `1.5rem` | Length of the fade at each edge.                           |
| `--tblr-scroll-shadow-offset-top` | `0px`    | Space at the top that is never faded, for a sticky header. |

The fade is a mask, not a color. It shows whatever is behind the container, so it works on any background and in dark mode without changes.

## Browser support

Scroll shadows are a progressive enhancement. They use scroll-driven animations (`animation-timeline: scroll()`), which Chrome, Edge and Safari support. Browsers without them, such as Firefox today, show the container without the fade. Scrolling and everything else works the same.

## Accessibility

- The fade is decorative. It does not replace a visible scrollbar or other cues that the content goes on.
- Give a scroll container that holds no focusable content `tabindex="0"`, so keyboard users can scroll it. The examples above do this.
- While the container has keyboard focus, the fade is turned off so that the focus ring stays fully visible.
