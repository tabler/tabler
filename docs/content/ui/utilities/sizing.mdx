## Width and height

`.w-*` and `.h-*` set the width or height in percent of the parent (`25`, `33`, `50`, `66`, `75`, `100`), on the spacing scale, or to `auto`.

<Example>
<div class="w-25 p-2 mb-2 bg-primary-lt rounded">Width 25%</div>
<div class="w-50 p-2 mb-2 bg-primary-lt rounded">Width 50%</div>
<div class="w-100 p-2 bg-primary-lt rounded">Width 100%</div>
</Example>

## Content-based sizes

`min-content`, `max-content`, and `fit-content` size the element by its content instead of its parent. Use them as `.w-fit-content`, `.h-max-content`, and so on.

- `min-content` is as narrow as the longest word.
- `max-content` fits the content on one line, even if it overflows the parent.
- `fit-content` fits the content but never grows wider than the parent.

<Example>
<div class="w-min-content p-2 mb-2 bg-primary-lt rounded">Min content width</div>
<div class="w-max-content p-2 mb-2 bg-primary-lt rounded">Max content width</div>
<div class="w-fit-content p-2 bg-primary-lt rounded">Fit content width</div>
</Example>
