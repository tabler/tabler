## Viewport

`.vw-100` and `.vh-100` set the width or height to the full viewport, and `.min-vw-100` and `.min-vh-100` set it as the minimum.

The dynamic versions `.dvw-100`, `.dvh-100`, `.min-dvw-100`, and `.min-dvh-100` use the `dvw` and `dvh` units. They follow the visible viewport, so a full-height section does not overflow on mobile while the browser shows its address bar.

```html
<section class="min-dvh-100">...</section>
<div class="dvh-100 overflow-auto">...</div>
```
