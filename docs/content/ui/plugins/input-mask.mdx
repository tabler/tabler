## Default markup

Use an input mask where the value has a fixed format, such as a phone number, a date or a card number.

To create an input mask, add the `data-mask` attribute to the input element:

```html
<input
  type="text"
  name="input-mask"
  class="form-control"
  data-mask="(00) 0000-0000"
  placeholder="(00) 0000-0000"
  autocomplete="off"
/>
```

<Example column>
<label class="form-label">Telephone mask</label>
<label class="form-label" for="mask-phone">Phone number</label>
<input type="text" id="mask-phone" name="input-mask" class="form-control" data-mask="(00) 0000-0000" data-mask-visible="true" placeholder="(00) 0000-0000" autocomplete="off" />
</Example>

## Pattern

| Character | Accepts |
| --- | --- |
| `0` | a digit |
| `a` | a letter |
| `*` | any character |
| `\` | makes the next character a literal, so `\0` is a plain `0` |

Every other character is a literal, and Tabler adds it for the user as they type. Paste works too: the value is cut to the pattern and the characters that do not fit are dropped.

<Example column>
<label class="form-label" for="mask-date">Date</label>
<input type="text" id="mask-date" class="form-control mb-3" data-mask="00/00/0000" placeholder="00/00/0000" autocomplete="off" />
<label class="form-label" for="mask-plate">Plate</label>
<input type="text" id="mask-plate" class="form-control" data-mask="aa-0000" data-mask-visible="true" autocomplete="off" />
</Example>

## Numbers

For amounts and other numbers, use `data-mask-type="number"` instead of a pattern. The user types freely and Tabler groups the thousands, keeps the fraction to `scale` digits and drops everything that is not a number.

<Example column>
<label class="form-label" for="mask-number">Number</label>
<input type="text" id="mask-number" class="form-control mb-3" data-mask-type="number" data-mask-scale="0" data-mask-thousands-separator=" " placeholder="1 234 567" autocomplete="off" />
<label class="form-label" for="mask-money">Money</label>
<input type="text" id="mask-money" class="form-control mb-3" data-mask-type="number" data-mask-prefix="$" data-mask-thousands-separator="," data-mask-min="0" data-mask-pad-fractional-zeros="true" placeholder="$0.00" autocomplete="off" />
<label class="form-label" for="mask-percent">Percent</label>
<input type="text" id="mask-percent" class="form-control" data-mask-type="number" data-mask-suffix=" %" data-mask-scale="1" data-mask-min="0" data-mask-max="100" placeholder="0 %" autocomplete="off" />
</Example>

```html
<input
  type="text"
  class="form-control"
  data-mask-type="number"
  data-mask-prefix="$"
  data-mask-thousands-separator=","
  data-mask-min="0"
  data-mask-pad-fractional-zeros="true"
/>
```

| Option | Attribute | Default | Description |
| --- | --- | --- | --- |
| `type` | `data-mask-type="number"` | | Turns the mask into a number mask. |
| `scale` | `data-mask-scale` | `2` | Digits after the radix. Use `0` for whole numbers. |
| `radix` | `data-mask-radix` | `.` | The fractional separator. |
| `thousandsSeparator` | `data-mask-thousands-separator` | none | The character that groups thousands. |
| `mapToRadix` | | `,` for `.`, `.` for `,` | Other characters that the user can type as the radix. |
| `min`, `max` | `data-mask-min`, `data-mask-max` | none | The range. A `min` of `0` or more also removes the minus sign. |
| `prefix`, `suffix` | `data-mask-prefix`, `data-mask-suffix` | none | Text around the number, such as a currency symbol. |
| `padFractionalZeros` | `data-mask-pad-fractional-zeros` | `false` | Adds zeros up to `scale` when the field loses focus. |

`unmaskedValue` is the number as plain text, with a `.` as the radix and no separators, so `parseFloat(unmaskedValue)` works whatever the format on screen. A value above `max` is cut down to `max` as the user types, and a value below `min` is raised to it when the field loses focus.

## Options

| Option | Attribute | Default | Description |
| --- | --- | --- | --- |
| `mask` | `data-mask` | `''` | The pattern, or a function that gets the unmasked value and returns the pattern. |
| `lazy` | `data-mask-visible="true"` | `true` | With `data-mask-visible` the whole pattern shows before the user types. |
| `placeholderChar` | `data-mask-placeholder-char` | `_` | The character for an empty slot when the pattern is visible. |
| `tokens` | | `{}` | Extra pattern characters, each with the RegExp one character has to match. |

<CodeDocs name="input-mask-init" file="core/js/src/input-mask.ts" />

Create the component yourself for a field added later. The config object wins over the attributes:

```js
const phone = new tabler.InputMask(document.getElementById('phone'), { mask: '(00) 0000-0000' });
```

A custom token, here a hexadecimal digit:

```js
new tabler.InputMask(document.getElementById('color'), {
  mask: '#HHHHHH',
  tokens: { H: /[0-9a-f]/i },
});
```

A function as the mask changes the pattern while the user types, for example for a card number:

```js
new tabler.InputMask(document.getElementById('card'), {
  mask: (value) => (/^3[47]/.test(value) ? '0000 000000 00000' : '0000 0000 0000 0000'),
});
```

### Methods and properties

| Name | Description |
| --- | --- |
| `value` | The value as shown, with the literals. |
| `unmaskedValue` | Only what the user typed. Send this one to a server. |
| `isComplete` | `true` when every slot is filled. |
| `update()` | Re-applies the mask after the value was changed from code. |
| `dispose()` | Removes the mask and the component from the element. |
| `getInstance(element)` | Static. Returns the component for the element, or `null`. |
| `getOrCreateInstance(element, config)` | Static. Returns the component for the element and creates it when needed. |

### Events

The events are triggered on the input.

| Event | Description |
| --- | --- |
| `accept.bs.input-mask` | The unmasked value changed. Has `value` and `unmaskedValue`. |
| `complete.bs.input-mask` | The last slot was filled. Has `value` and `unmaskedValue`. |

```js
input.addEventListener('complete.bs.input-mask', (event) => {
  console.log(event.unmaskedValue);
});
```

## Accessibility

- A mask changes what the field accepts as the user types, which is easy to lose track of without sight. Say the expected format in a hint tied to the field with `aria-describedby`.
- Keep a real `label`. The placeholder shows the pattern, and it disappears as soon as typing starts.
- Do not block paste. A masked field that rejects a pasted phone number is a dead end for anyone using a password manager or a switch device.
- Use the right `type` and `autocomplete`, so the browser can still fill the field and the phone keyboard matches.
