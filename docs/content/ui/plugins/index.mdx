Plugins add features that not every project needs, so none of them are part of the core CSS and JavaScript. Some wrap a third-party library, such as charts, calendars, file uploads or the WYSIWYG editor - those need that library on the page as well. Others, like country flags, payment provider logos, social icons and extra theme base colors, only ship an extra stylesheet. Either way you load a plugin on demand, and pages that need it list the files at the top.
