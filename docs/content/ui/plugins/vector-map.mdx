## Overview

A vector map draws countries as SVG paths, so it stays sharp at any size. Use it to show a number per country, a few places, or routes between them.

The component is Tabler's own. It needs no map library, no API key and no network request. The country shapes come from [Natural Earth](https://www.naturalearthdata.com/), which is public domain.

## Installation

The vector map is not part of `tabler.js`, so pages without a map do not load it. Add two files after `tabler.js`: the component and the map data.

<Code
	lang="html"
	code={`<script src="${site.cdnUrl}/dist/js/tabler.min.js"></script>
<script src="${site.cdnUrl}/dist/js/tabler-vector-map.min.js"></script>
<script src="${site.cdnUrl}/dist/js/maps/world.js"></script>`}
/>

The styles are part of `tabler.css`.

With a bundler, import the component and the map, then register the map under a name:

```js
import { VectorMap } from '@tabler/core/dist/js/tabler-vector-map.esm.js';
import { world } from '@tabler/core/dist/js/maps/world.esm.js';

VectorMap.addMap('world', world);
```

## Default markup

Add `class="vector-map"` and `data-bs-toggle="vector-map"` to an empty element. Tabler draws the map on page load. The map is as wide as its parent and keeps its own proportions, so it needs no height.

Set `data-bs-label` to a short text that says what the map shows. Without it the map is hidden from screen readers.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-label="World map"></div>
</Example>

## Values

Pass a number per country in `data-bs-values`, as a JSON object. The keys are ISO 3166-1 alpha-2 codes, such as `PL` or `US`. The country with the highest value gets the full color and the others get a lighter shade.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-label="Visits by country" data-bs-values='{"US": 100, "CA": 62, "BR": 48, "GB": 71, "DE": 80, "FR": 66, "PL": 54, "IN": 90, "CN": 85, "JP": 59, "AU": 40, "ZA": 22, "EG": 18, "MX": 35, "AR": 27}'></div>
</Example>

The shades are spread between the lowest and the highest value. Set `data-bs-min` and `data-bs-max` to use a fixed range instead, for example `0` and `100` for a percentage.

### Color

The map uses the primary color. Set `--tblr-vector-map-color` to change it.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-label="Growth by country" data-bs-min="0" data-bs-values='{"US": 4, "CA": 7, "BR": 9, "DE": 3, "PL": 8, "IN": 10, "CN": 6, "AU": 5}' style="--tblr-vector-map-color: var(--tblr-green)"></div>
</Example>

## Markers

Markers point at single places, such as offices or customers. Pass them in `data-bs-markers` as a JSON array. Each marker has a `lat`, a `lng` and an optional `name`. A marker keeps its size when the map is resized or zoomed.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-label="Our offices" data-bs-markers='[{"name": "Warsaw", "lat": 52.23, "lng": 21.01}, {"name": "New York", "lat": 40.71, "lng": -74.01}, {"name": "Tokyo", "lat": 35.68, "lng": 139.69}, {"name": "Sydney", "lat": -33.87, "lng": 151.21}]' style="--tblr-vector-map-color: var(--tblr-red)"></div>
</Example>

## Lines

Lines join two markers, for a route or a connection. Pass them in `data-bs-lines` as a JSON array. `from` and `to` are the names of two markers. The dashes move from the start of the line to its end, and stand still for users who ask for reduced motion.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-label="Flights from Warsaw" data-bs-markers='[{"name": "Warsaw", "lat": 52.23, "lng": 21.01}, {"name": "New York", "lat": 40.71, "lng": -74.01}, {"name": "Tokyo", "lat": 35.68, "lng": 139.69}, {"name": "Cape Town", "lat": -33.92, "lng": 18.42}]' data-bs-lines='[{"from": "Warsaw", "to": "New York"}, {"from": "Warsaw", "to": "Tokyo"}, {"from": "Warsaw", "to": "Cape Town"}]'></div>
</Example>

## Zoom

Add `data-bs-zoom="true"` to let users look closer. The map gets two buttons, and reacts to the mouse wheel, a double click, a pinch and a drag.

<Example>
<div class="vector-map" data-bs-toggle="vector-map" data-bs-zoom="true" data-bs-label="Visits in Europe" data-bs-values='{"PL": 8, "DE": 6, "FR": 5, "ES": 3, "IT": 4, "GB": 7, "SE": 2, "UA": 3, "RO": 2, "CZ": 5}'></div>
</Example>

While the pointer is over a zoomable map, the wheel zooms the map and does not scroll the page. Set `data-bs-zoom-on-scroll="false"` to keep the wheel for the page. On a touch screen a finger on the map moves the map, not the page, so leave some room around a large map.

## Tooltip

A tooltip shows the name of the country or marker under the pointer, with the value when the country has one. Set `data-bs-tooltip="false"` to turn it off.

Pass a function from JavaScript to write your own text. It gets the item under the pointer and returns a string. The string is shown as plain text. Return an empty string to show nothing.

```js
new tabler.VectorMap('#visits', {
  values: { PL: 54, DE: 80 },
  tooltip: (item) => (item.type === 'region' && item.value !== undefined ? `${item.name}: ${item.value}%` : item.name),
});
```

## Options

Set options with data attributes or pass them to the constructor. For a data attribute, add `data-bs-` to the name and write it in kebab case, for example `data-bs-zoom-max`.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `map` | string, object | `'world'` | Name of a loaded map, or the map data itself. |
| `values` | object | `{}` | A number per region code. |
| `min` | number, null | `null` | Value that gets the lightest shade. The lowest value when `null`. |
| `max` | number, null | `null` | Value that gets the full color. The highest value when `null`. |
| `markers` | array | `[]` | Places as `{ name, lat, lng }`. |
| `lines` | array | `[]` | Connections as `{ from, to }`, by marker name. |
| `tooltip` | boolean, function | `true` | Shows a tooltip, or builds its text. |
| `zoom` | boolean | `false` | Lets users zoom and drag the map. |
| `zoomMax` | number | `8` | The largest magnification. |
| `zoomOnScroll` | boolean | `true` | Zooms with the mouse wheel. Needs `zoom`. |
| `zoomInLabel` | string | `'Zoom in'` | Accessible name of the zoom in button. |
| `zoomOutLabel` | string | `'Zoom out'` | Accessible name of the zoom out button. |
| `label` | string, null | `null` | Accessible name of the map. |

## JavaScript

Tabler wraps the element in a `VectorMap` component that works like the Bootstrap components: it is created once per element and stored on it. When the page is loaded, Tabler creates one for every element with `data-bs-toggle="vector-map"`. This is the code that runs:

<CodeDocs name="vector-map-init" file="core/js/src/vector-map.ts" />

Create the component yourself for an element added later, or to pass the data from code:

```js
const visits = tabler.VectorMap.getOrCreateInstance(document.getElementById('visits'), {
  values: { PL: 54, DE: 80, FR: 66 },
});
```

Call `update()` with new values to shade the map again. The map is not drawn again, so this is cheap enough for live data:

```js
visits.update({ PL: 61, DE: 77, FR: 70 });
```

| Method | Description |
| --- | --- |
| `update(values)` | Shades the regions with new values. Fires `updated.bs.vector-map`. |
| `render()` | Reads the attributes again and draws the map from the start. Fires `rendered.bs.vector-map`. |
| `zoomIn()` | Zooms in one step, around the middle of the view. |
| `zoomOut()` | Zooms out one step. |
| `reset()` | Goes back to the whole map. |
| `dispose()` | Removes the map, the buttons, the tooltip and the component from the element. |
| `VectorMap.addMap(name, data)` | Static. Registers a map under a name. |
| `getInstance(element)` | Static. Returns the component for the element, or `null`. |
| `getOrCreateInstance(element, config)` | Static. Returns the component for the element and creates it when needed. |

| Event | Description |
| --- | --- |
| `rendered.bs.vector-map` | Fired on the element after every render. |
| `updated.bs.vector-map` | Fired on the element after `update()`. |

## Styling a single country

Every country is a path with its code in `data-region`, so one rule can style it:

```css
.vector-map [data-region='PL'] {
  fill: var(--tblr-red);
}
```

## Custom properties

The map reads its colors and sizes from custom properties on the element. Change them for one map with a `style` attribute, or for a section with a class.

| Property | Default | Description |
| --- | --- | --- |
| `--tblr-vector-map-color` | `var(--tblr-primary)` | Color of the highest value, and of the markers. |
| `--tblr-vector-map-region-fill` | `var(--tblr-border-color)` | Fill of a country with no value. |
| `--tblr-vector-map-region-stroke` | `var(--tblr-bg-surface)` | Border between countries. |
| `--tblr-vector-map-region-stroke-width` | `1px` | Width of the border. |
| `--tblr-vector-map-value-min` | `0.1` | Share of the color the lowest value gets, from 0 to 1. |
| `--tblr-vector-map-marker-size` | `0.5rem` | Diameter of a marker. |
| `--tblr-vector-map-marker-color` | `var(--tblr-vector-map-color)` | Color of a marker. |
| `--tblr-vector-map-marker-halo-color` | `var(--tblr-bg-surface)` | Color of the ring around a marker. |
| `--tblr-vector-map-marker-halo-width` | `2px` | Width of the ring. |
| `--tblr-vector-map-line-color` | `var(--tblr-secondary)` | Color of a line. |
| `--tblr-vector-map-line-width` | `1px` | Width of a line. |
| `--tblr-vector-map-line-dash` | `4px` | Length of a dash and of the gap after it. |
| `--tblr-vector-map-line-duration` | `1s` | Time one dash takes to move to the place of the next. |
| `--tblr-vector-map-controls-offset` | `var(--tblr-spacer-2)` | Distance of the zoom buttons from the corner. |

## The world map

The world map has 176 countries in the Miller projection, without Antarctica. It is made for an overview, so very small countries, such as Singapore or Malta, are not on it. Values for a code that is not on the map are skipped.

Three territories have no ISO code. The map uses `XK` for Kosovo, `XC` for Northern Cyprus and `XS` for Somaliland. Borders follow the default view of Natural Earth.

## Accessibility

- Set `data-bs-label`. The map is then an image with that name. The countries themselves are not read out one by one.
- The data behind the map has to be reachable another way. Put a table of the same values next to or below the map. It serves screen reader users and anyone who prints the page.
- The tooltip is for the pointer only. Do not put anything there that is not in the text version too.
- Shades of one color are hard to tell apart for many users. Add a legend with the real numbers.
- The zoom buttons work with the keyboard and have accessible names. Change the names with `data-bs-zoom-in-label` and `data-bs-zoom-out-label` when the page is not in English.
