# Spinners

Based on `/preview/pages/all-elements.html` and `/shared/includes/ui/spinner.html` in this repository.

## Base structure

```html
<div class="spinner-border text-primary" role="status"></div>
<div class="spinner-grow text-warning" role="status"></div>
```

## Types

```html
<!-- Border spinner -->
<div class="spinner-border" role="status"></div>

<!-- Grow spinner -->
<div class="spinner-grow" role="status"></div>
```

## Colors

```html
<div class="spinner-border text-primary" role="status"></div>
<div class="spinner-border text-success" role="status"></div>
<div class="spinner-border text-warning" role="status"></div>
<div class="spinner-border text-danger" role="status"></div>
```

## Sizes

```html
<div class="spinner-border spinner-border-sm" role="status"></div>
<div class="spinner-border" role="status"></div>
```

## Classes

| Class | Purpose |
|-------|-----------|
| `spinner-border` | Border spinner |
| `spinner-border-sm` | Small spinner |
| `spinner-grow` | Spinner grow |
| `spinner-grow-sm` | Small grow spinner |
| `text-{color}` | Spinner color |
