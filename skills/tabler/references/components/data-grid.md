# Data Grid

Based on `/preview/pages/datagrid.html` in this repository.

## Base structure

```html
<div class="datagrid">
  <div class="datagrid-item">
    <div class="datagrid-title">Name</div>
    <div class="datagrid-content">John Doe</div>
  </div>
  <div class="datagrid-item">
    <div class="datagrid-title">Email</div>
    <div class="datagrid-content">john@example.com</div>
  </div>
</div>
```

## Classes

| Class | Purpose |
|-------|-----------|
| `datagrid` | Container grid |
| `datagrid-item` | Item individual |
| `datagrid-title` | Field label |
| `datagrid-content` | Field value |
