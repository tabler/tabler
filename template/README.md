# Tabler UI Template

This is a reusable template based on the Tabler UI kit. It includes all the necessary assets to get you started with a professional-looking dashboard.

## Features

- **Responsive Design:** Works on all screen sizes.
- **Dark Mode:** Supports both light and dark themes.
- **Component Library:** Includes a variety of UI components like buttons, forms, and more.

## How to Use

### Dark Mode

To enable dark mode, click the sun/moon icon in the header. The theme will be saved in your browser's local storage and will be remembered on your next visit.
