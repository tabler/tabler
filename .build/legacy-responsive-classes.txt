# Every responsive class Tabler 1.x emits, frozen.
#
# Read by .build/postcss-legacy-responsive.ts, which aliases each of these onto
# the prefixed class that replaces it, so markup written for 1.x keeps working
# after the infix -> prefix move (see BOOTSTRAP-V6-MIGRATION.md, phase 8).
#
# Built from the 1.x stylesheet, then narrowed to the classes the 2.0 build
# actually renames: sitting inside a media query is not enough to be responsive.
# `.card-md` and `.modal-lg` are size modifiers that happen to be declared in
# one, and aliasing them would invent a `.md\:card` that never existed.
#
# Deliberately static from here on. It describes a released class surface, so it
# must not be regenerated from a later build — a class 2.0 drops has to stay
# listed, or the compatibility silently goes with it. It is deleted together
# with the plugin, one major after 2.0.
#
# Each name carries exactly one breakpoint segment; the plugin removes it to get
# the prefixed spelling (`col-md-6` -> `md:col-6`).
