# Every class Tabler 1.x emitted that 2.0 renames, as `<2.0 name> <1.x name>`.
#
# Read by .build/postcss-legacy-classes.ts, which adds the 1.x name back as a
# second selector on the 2.0 rule, and by .build/codemod-class-prefix.ts, which
# rewrites markup in the other direction. Three kinds of rename live here:
#
#   md:col-6            col-md-6                breakpoint
#   print:d-none        d-print-none            print
#   hover:link-opacity-50  link-opacity-50-hover  state
#
# Written out rather than derived. The breakpoint pairs could be worked out by
# moving a segment, but the three kinds put the segment in different places, and
# nothing in the name itself separates `btn-sm` (a size, not renamed) from
# `col-md-6` (a breakpoint). Built by diffing the 1.x and 2.0 stylesheets across
# every bundle: 2 505 classes left 1.x, 2 505 arrived in 2.0, and they paired up
# with nothing unmatched on either side.
#
# Deliberately static from here on. It describes a released class surface, so it
# must not be regenerated from a later build — a class 2.0 drops has to stay
# listed, or the compatibility silently goes with it. It is deleted together
# with the plugin, one major after 2.0.
