# What the working tree no longer ships compared with the last release of
# @tabler/core - see check-compat.ts. The check fails on any break that is not
# listed here, and on a listed one that no longer breaks, so fixing one means
# deleting its line.
#
# A plain line is a break that still has to be fixed before the release:
# `check-compat --strict` fails while one is left. Add ` # accepted: <why>`
# to a line only after the maintainers decided to ship the break, for example
# an override for a class that a third-party library dropped.
#
# Everything below entered `dev` between 1.5.1 and 1.6.0, before the check existed.
